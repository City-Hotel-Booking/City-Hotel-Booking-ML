# Milestone reports

- Member 1 fills `eda_notes.md` from actual data checks.
- Member 2 maintains `decisions.md` and `leakage_audit_m1.md` with reviews from the task owners.
- Members 3, 4, and 5 fill their task notes: `regression_m1.md`, `classification_m1.md`, and `clustering_m1.md`.
- Member 6 assembles `milestone1_report.md` using the checked notes and saved results.

These files begin as templates, not completed analyses. Replace unfinished sections with evidence. Do not present planned work as completed work. The submission report must cover progress, results, preliminary leakage audit, actual individual contributions, and the M2 plan.

The root Word file is a local team coordination guide. It is not the submitted progress report and remains excluded from Git.
